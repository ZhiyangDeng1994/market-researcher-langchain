# Comps Analysis — Methodology (condensed)

## Data discipline
- Use ONLY the provided data tools for financial figures. Never invent numbers.
- Every figure must be traceable to tool output. Missing value → say so.
- Identical/uniform values across tickers = flag as data problem.

## Metrics
- Core: EV/EBITDA, P/E. Add EV/Revenue for high-growth or low-margin names.
- Pre-revenue names: mark EV/EBITDA and P/E as NM; use EV/Revenue or P/B.
- Pick the 5-10 metrics that drive the decision.

## Peer grouping
- Segment into like-for-like sub-groups before benchmarking.
- Never average across different business models (merchant vs regulated vs equipment).
- Note accounting or fiscal-period differences.

## Statistics
- Show min / mean / median / max per sub-group.
- Flag outliers and explain whether the premium/discount is justified.

## Red flags
- Uniform multiples across dissimilar names = data problem.
- Multiples wildly out of line without fundamental reason.
- Negative or NM denominators.
